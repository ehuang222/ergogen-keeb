# ergogen-keeb
Wireless (BLE) ergonomic split mechanical keyboard generated with Ergogen. Heavily inspired by [keyzog's Kapl](https://github.com/keyzog/kapl) and [omkbd's Ergodash](https://github.com/omkbd/ErgoDash) keyboards.

This is _very_ WIP and my first foray into PCB design and 3D modeling. Be warned, stuff in this repo will likely be broken and very jank.
